# Inventory System

**Product Registration and Total Cost Calculation**

## Description

This Python program registers a product by requesting its name, price, and quantity. It validates the input data, calculates the total cost, and displays the result.

---

## How it works

1. The user enters the product name, price, and quantity.
2. The system validates that price and quantity are greater than zero.
3. The total cost is calculated (price × quantity).
4. The result is displayed on screen.
